# Auto Sales & Service Dashboard (Looker Studio)

## 📊 Project Overview
This project presents an interactive dashboard built with Google Looker Studio to analyze auto sales performance, service issues, and customer sentiment. The dashboard supports monitoring both financial and operational KPIs.

## 🛠 Tools Used
- Google Looker Studio
- Data Visualization
- KPI Scorecards

## 📁 Dataset
Dataset includes:
- Monthly sales and profit data
- Vehicle models and dealer locations
- Recall records by system type
- Customer sentiment classifications

## 🔍 Dashboard Features
### Sales Metrics
- Total Quantity Sold(58k+)
- Total Profit ($78M+)
- Average Quantity Sold(19)
- Quantity Sold by Vehicle Model
- Profit by Dealer ID

### Trend Analysis
- Monthly sales and profit trends
- Identification of peak and low performance periods

### Service & Feedback Analysis
- Recall count per vehicle model
- Breakdown of affected vehicle systems (airbags, suspension, tires, powertrain, etc.)
- Customer sentiment hierarchy (Positive, Neutral, Negative)

## 📈 Business Insights
- Enables tracking of sales and profit performance over time
- Helps identify models with frequent service issues
- Supports linking customer feedback with product and service quality
